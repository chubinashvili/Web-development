🚀 Git და GitHub სახელმძღვანელო

VS Code GitHub Pull Requests გაფართოების გამოყენება

რეპოზიტორის ინიციალიზაცია

1

VS Code-ის გახსნა

გახსენით VS Code და გადადით თქვენს პროექტის საქაღალდეში File → Open Folder

2

Source Control პანელის გახსნა

დააჭირეთ Source Control ხატულას მარცხენა პანელზე ან გამოიყენეთ Ctrl + Shift + G

3

რეპოზიტორის ინიციალიზაცია

დააჭირეთ Initialize Repository ღილაკს

ეს შექმნის ახალ Git რეპოზიტორს თქვენს საქაღალდეში .git დირექტორიით

კომიტების შექმნა

1

ფაილების დამატება Stage-ზე

Source Control პანელში დააჭირეთ + ნიშანს ფაილის გასწვრივ ან დააჭირეთ Stage All Changes

2

კომიტის შეტყობინების დაწერა

შეიყვანეთ აღწერილობითი შეტყობინება Message ველში

მაგალითი: "დავამატე ახალი ფუნქციონალი მომხმარებლის ავტორიზაციისთვის"
3

კომიტის შესრულება

დააჭირეთ ✓ Commit ღილაკს ან Ctrl + Enter

კარგი პრაქტიკაა ხშირი და მცირე კომიტების გაკეთება დიდი ცვლილებების ნაცვლად

ცვლილებების სინქრონიზაცია Branch-თან

1

GitHub-თან დაკავშირება

პირველად დააჭირეთ Publish Branch ღილაკს

აირჩიეთ GitHub რეპოზიტორი და დაადასტურეთ ავტორიზაცია

2

ცვლილებების Push

კომიტების შემდეგ დააჭირეთ Sync Changes ღილაკს

დარწმუნდით, რომ ყველა ლოკალური ცვლილება დაკომიტებულია Push-ის წინ

3

ცვლილებების Pull

სხვების ცვლილებების მისაღებად გამოიყენეთ იგივე Sync Changes ღილაკი

ახალი Branch-ის შექმნა

1

Branch პანელის გახსნა

ქვედა მარცხენა კუთხეში დააჭირეთ Branch-ის სახელს

2

ახალი Branch-ის შექმნა

აირჩიეთ Create new branch

შეიყვანეთ Branch-ის სახელი და დააჭირეთ Enter

მაგალითი: feature/user-authentication
3

Branch-ზე გადართვა

ავტომატურად გადაერთვებით ახალ Branch-ზე

შეგიძლიათ ნებისმიერ დროს გადაერთოთ Branch-ებს შორის იგივე მენიუდან

Pull Request-ის შექმნა

1

GitHub Pull Requests პანელის გახსნა

მარცხენა პანელში დააჭირეთ GitHub ხატულას

დარწმუნდით, რომ დაინსტალირებული გაქვთ "GitHub Pull Requests and Issues" გაფართოება

2

Pull Request-ის დაწყება

დააჭირეთ Create Pull Request ღილაკს

აირჩიეთ base branch (ჩვეულებრივ main) და compare branch (თქვენი feature branch)

3

PR-ის დეტალების შევსება

დაამატეთ სათაური და აღწერა თქვენს Pull Request-ს

სათაური: "ახალი ფუნქცია: მომხმარებლის ავტორიზაცია" აღწერა: "დავამატე ავტორიზაციის სისტემა JWT ტოკენების გამოყენებით..."
4

PR-ის გაგზავნა

დააჭირეთ Create ღილაკს PR-ის შესაქმნელად.

შეგიძლიათ დაამატოთ რევიუერები და ლეიბლები PR-ის შექმნის შემდეგ.

5

PR-ის მართვა

შეგიძლიათ ნახოთ და მართოთ თქვენი PR-ები პირდაპირ VS Code-იდან

კომენტარების დამატება, რევიუს მოთხოვნა და merge-ის შესრულება შესაძლებელია გაფართოებიდან
