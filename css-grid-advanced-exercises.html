Exercise 2: Magazine-Style Article Layout

Advanced

📰 Your Mission:

Create a sophisticated magazine layout with asymmetric article placement.

  • Magazine header spans full width
  • Featured article takes 2/3 width and 2 rows height
  • Side articles stack vertically in remaining 1/3 space
  • Ad space at the bottom spans 2 columns
  • Use grid areas for precise positioning
TECH MAGAZINE - Latest News & Reviews
🌟 Featured: The Future of Web Development
📱 Mobile Trends 2024
🤖 AI in Design
🚀 Performance Tips
📢 Advertisement Space
.magazine-layout {
  display: grid;
  grid-template-columns: 2fr 1fr;
  grid-template-areas:
    "header header"
    "featured side1"
    "featured side2"
    "featured side3"
    "ad ad";
  gap: 20px;
}

.magazine-header { grid-area: header; }
.featured-article { grid-area: featured; }
.side-article:nth-child(3) { grid-area: side1; }
.side-article:nth-child(4) { grid-area: side2; }
.side-article:nth-child(5) { grid-area: side3; }
.ad-space { grid-area: ad; }

Exercise 3: E-commerce Product Showcase

Intermediate

🛍️ Your Mission:

Build a responsive product grid with featured items that span multiple cells.

  • Create a responsive grid with auto-fit and minmax(250px, 1fr)
  • Featured product spans 2x2 grid cells
  • Regular products fill remaining spaces
  • 30px gaps between all products
  • Grid should center itself when there aren't enough items to fill a row

Exercise 4: Enterprise Dashboard Layout

Expert

📊 Your Mission:

Create a complex dashboard with multiple widget sizes and a sidebar navigation.

  • Header spans full width (all columns)
  • Sidebar navigation spans full height (2 rows)
  • Large chart widget spans 2 columns and 1 row
  • Small stats widgets fill 1x1 spaces
  • Activity feed spans remaining bottom space
  • Use both grid areas and span properties

.complex-dashboard {
  display: grid;
  grid-template-columns: 200px 1fr 1fr 1fr;
  grid-template-rows: auto 1fr 1fr;
  grid-template-areas:
    "header header header header"
    "sidebar chart chart stats1"
    "sidebar activity activity stats2";
  gap: 20px;
  min-height: 600px;
}

.dashboard-header { grid-area: header; }
.sidebar-nav { grid-area: sidebar; }
.chart-widget { grid-area: chart; }
.stats-widget:nth-child(4) { grid-area: stats1; }
.stats-widget:nth-child(6) { grid-area: stats2; }
.activity-feed { grid-area: activity; }
