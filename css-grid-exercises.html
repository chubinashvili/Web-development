სავარჯიშო 1: რესპონსივი ფოტო გალერეა

📋 თქვენი ამოცანა:

შექმენით რესპონსივი ფოტო გალერეა CSS Grid-ის გამოყენებით.

  • გაითვალისწინეთ რესპონსივობა (3 სვეტი დესკტოპზე, 2 ტაბლეტზე, 1 მობილურზე)
  • დაამატეთ 20px ინტერვალი ფოტოებს შორის
  • გამოიყენეთ auto-fit minmax(200px, 1fr)-თან ერთად
  • გახადეთ მე-5 ფოტო 2 სვეტზე გადაშლილი

სავარჯიშო 2: კლასიკური ბლოგის განლაგება

📋 თქვენი ამოცანა:

შექმენით ტიპური ბლოგის განლაგება header-ით, nav-ით, მთავარი კონტენტით, sidebar-ით და footer-ით.

  • Header-ი უნდა იყოს სრული სიგანის ზემოთ
  • ნავიგაცია header-ის ქვემოთ, ასევე სრული სიგანის
  • მთავარი კონტენტი იკავებს ადგილის 2/3-ს, sidebar-ი 1/3-ს
  • Footer-ი სრულ სიგანეზე ყველაზე ქვემოთ
  • 15px ინტერვალი ყველა სექციას შორის

.blog-layout {
  display: grid;
  grid-template-columns: 2fr 1fr;
  grid-template-areas:
    "header header"
    "nav nav"
    "main sidebar"
    "footer footer";
  gap: 15px;
}

.blog-header { grid-area: header; }
.blog-nav { grid-area: nav; }
.blog-main { grid-area: main; }
.blog-sidebar { grid-area: sidebar; }
.blog-footer { grid-area: footer; }

სავარჯიშო 3: ადმინისტრაციული დაკმის პანელი

📋 თქვენი ამოცანა:

შექმენით დაკმის პანელი სხვადასხვა ზომის ვიჯეტებით.

  • შექმენით 4-სვეტიანი ბადე
  • პატარა ვიჯეტები: თითო სვეტი თითოეულისთვის (4 სულ პირველ მწკრივში)
  • დიდი ვიჯეტი: 2 სვეტსა და 2 მწკრივზე გაშლილი
  • გრაფიკის ვიჯეტი: 2 სვეტზე ჰორიზონტალურად გაშლილი
  • 20px ინტერვალი ვიჯეტებს შორის

სავარჯიშო 4: რესპონსივი ბარათების განლაგება

📋 თქვენი ამოცანა:

შექმენით რესპონსივი ბარათების განლაგება, რომელიც ეკრანის ზომას ეადაპტირება.

  • ბარათების მინიმალური სიგანე უნდა იყოს 250px
  • ბარათები უნდა იზრდებოდნენ ხელმისაწვდომი ადგილის შევსებისთვის
  • გამოიყენეთ auto-fit რესპონსივი ქცევისთვის
  • 30px ინტერვალი ბარათებს შორის
  • ცენტრირეთ ბადე, თუ ბარათები არ ავსებენ სიგანეს

🏆 ბონუს გამოწვევა: წმინდა გრაალის განლაგება

📋 საბოლოო ტესტი:

შექმენით ცნობილი "წმინდა გრაალის" განლაგება - კლასიკური ვებ დიზაინის შაბლონი!

  • Header ზემოთ (სრული სიგანე)
  • Footer ქვემოთ (სრული სიგანე)
  • 3 სვეტი შუაში: მარცხენა sidebar (200px), მთავარი კონტენტი (მოქნილი), მარჯვენა sidebar (200px)
  • მთავარი კონტენტის ადგილი უნდა იყოს მინიმუმ 400px სიგანის
  • განლაგება უნდა ავსებდეს მთელ ეკრანის სიმაღლეს

მინიშნება: დაგჭირდებათ grid-template-rows minmax()-სთან ერთად და min-height თვისება!
