🎯 CSS Grid-ის საფუძვლები

დაეუფლეთ ყველაზე მეტად გამოყენებულ Grid თვისებებს ყოველდღიური განლაგებისთვის

1. ძირითადი Grid კონტეინერი

CSS Grid-ის საფუძველი - ელემენტის Grid კონტეინერად გარდაქმნა.

display: grid;
grid-template-columns: 1fr 1fr 1fr;
gap: 15px;

2. სხვადასხვა ზომის სვეტები

განსხვავებული ერთეულების შერევა: fr, px, %, auto - მოქნილი განლაგებისთვის.

grid-template-columns: 2fr 1fr 1fr;
/* პირველი სვეტი იკავებს დანარჩენების 2-ჯერ მეტ ადგილს */

3. რიგების განსაზღვრა და Repeat-ის გამოყენება

ორივე განზომილების კონტროლი და repeat() ფუნქციის გამოყენება უფრო სუფთა კოდისთვის.

grid-template-columns: repeat(3, 1fr);
grid-template-rows: 100px 150px;
gap: 15px;

4. Grid შაბლონის არეები (დასახელებული რეგიონები)

შექმენით სემანტიკური განლაგებები დასახელებული არეებით - იდეალურია გვერდის განლაგებისთვის!

grid-template-areas:
"header header header"
"sidebar main main"
"footer footer footer";

/* შემდეგ შვილ ელემენტებში: */
grid-area: header;

5. ადაპტირებული Grid-ები Auto-fit-თან ერთად

შექმენით ადაპტირებული Grid-ები media queries-ის გარეშე!

grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
/* ელემენტები ავტომატურად ეწყობა, როცა ადგილი ნაკლებია */

💡 auto-fit vs auto-fill:
• auto-fit: ელემენტებს ავრცელებს კონტეინერის შესავსებად
• auto-fill: ინარჩუნებს ელემენტის ზომას, ტოვებს ცარიელ სივრცეს

6. განლაგების თვისებები

თქვენი Grid-ის და ელემენტების სრულყოფილი ცენტრირება და განლაგება.

justify-content: center; /* ჰორიზონტალური განლაგება */
align-content: center; /* ვერტიკალური განლაგება */
justify-items: stretch; /* ელემენტები უჯრედებში */
align-items: stretch; /* ელემენტები უჯრედებში */

7. ელემენტების გავრცელება და განთავსება

ელემენტების რამდენიმე რიგი/სვეტზე გავრცელება.

grid-column: span 2; /* 2 სვეტზე გავრცელება */
grid-row: span 2; /* 2 რიგზე გავრცელება */
/* ან გამოიყენეთ ხაზის ნომრები: */
grid-column: 1 / 3; /* 1-ე ხაზიდან მე-3-მდე */

📋 სწრაფი მიმოხილვის სახელმძღვანელო

კონტეინერის თვისებები

display: grid; - Grid კონტეინერის შექმნა

grid-template-columns - სვეტების განსაზღვრა

grid-template-rows - რიგების განსაზღვრა

grid-template-areas - დასახელებული არეები

gap / grid-gap - ელემენტებს შორის სივრცე

განლაგება (კონტეინერი)

justify-content - Grid-ის ჰორიზონტალური განლაგება

align-content - Grid-ის ვერტიკალური განლაგება

justify-items - ელემენტების ჰორიზონტალური განლაგება

align-items - ელემენტების ვერტიკალური განლაგება

place-content - ორივეს მოკლე ფორმა

ელემენტის თვისებები

grid-column - სვეტის პოზიცია/გავრცელება

grid-row - რიგის პოზიცია/გავრცელება

grid-area - დასახელებული არე ან მოკლე ფორმა

justify-self - საკუთარი ჰორიზონტალური განლაგება

align-self - საკუთარი ვერტიკალური განლაგება

სასარგებლო მნიშვნელობები

fr - წილადის ერთეული

repeat() - განმეორების შაბლონი

minmax() - მინიმალური და მაქსიმალური ზომა

auto-fit - ხელმისაწვდომ სვეტებში ჩატევა

span X - X სვეტი/რიგის გავრცელება

🎯 ყოველდღიური გამოყენების რეზიუმე:
თქვენი Grid განლაგებების 90% გამოიყენებს ამ თვისებებს:
• display: grid + grid-template-columns + gap (ძირითადი კონფიგურაცია)
• repeat(auto-fit, minmax(X, 1fr)) (ადაპტირებული ბარათები)
• grid-area ან grid-column/row: span X (სპეციალური განლაგებები)
• justify-content/align-content: center (ცენტრირება)
